The Windows bundle is built by `packaging/windows/build-release.ps1` against the vcpkg `ffmpeg[x264,zlib]` port, which
enables the same GPL components as the Linux build: FFmpeg (GPL-2.0-or-later as built with `--enable-gpl`) and x264
(GPL-2.0-or-later, shipped as a separate DLL beside `pulsar-desktop.exe`). The exact FFmpeg and x264 versions are the
ones resolved by the vcpkg baseline recorded in the CI logs for the release commit; their unmodified upstream sources
are available from <https://ffmpeg.org/releases/> and <https://code.videolan.org/videolan/x264>. The written offer in

## 2. The FFmpeg we ship

Built by [`packaging/linux/build-ffmpeg.sh`](packaging/linux/build-ffmpeg.sh) from the **unmodified** upstream
`ffmpeg-6.1.1.tar.xz` (sha256 `8684f4b00f94b85461884c3719382f1261f0d9eb3d59640a1f4ac0873616f968`) and the
x264 source `x264_0.164.3108+git31e19f9.orig.tar.gz` (sha256 `41606cb8e788a7f8c4514290646d4ba5c7bc68d9e1ccd1a73f446a90546913eb`).
Compiler: GCC 13.3 on Ubuntu 24.04. The exact commands are recorded in `usr/share/doc/pulsar-third-party/FFMPEG-BUILDINFO.txt`:

```text
x264:   --enable-static --enable-pic --bit-depth=8 --disable-cli --disable-opencl --disable-avs
        --disable-swscale --disable-lavf --disable-ffms --disable-gpac --disable-lsmash
FFmpeg: --enable-shared --disable-static --enable-pic --enable-gpl --enable-version3
        --disable-autodetect --disable-programs --disable-doc --disable-debug --disable-avdevice
        --disable-avfilter --disable-postproc --disable-network --enable-zlib --enable-libdav1d
        --enable-libx264 --extra-ldflags=-Wl,--exclude-libs,libx264.a --pkg-config-flags=--static
```

Everything else is FFmpeg's own native code (all native demuxers and decoders, the native AAC encoder, `libswscale`,
`libswresample`). PULSAR itself uses libavformat/libavcodec/libavutil/libswscale/libswresample.

## 3. Your rights to replace the libraries

The Qt and FFmpeg libraries are shared libraries in `usr/lib`. You may replace them with your own builds (same
sonames) or run PULSAR against other versions: for the tar.gz, drop them into `usr/lib`; for the AppImage run
`./PULSAR-0.2.0-beta.1-x86_64.AppImage --appimage-extract` and edit `squashfs-root/usr/lib`.
To rebuild the whole thing from source see section 5.

## 5. Rebuilding

```sh
git clone https://github.com/franduartedev/pulsar && cd pulsar && git checkout <release commit>
sudo apt install libdav1d-dev nasm   # plus the build dependencies in README.md
./packaging/linux/build-ffmpeg.sh    # unpacks and builds the pinned FFmpeg + x264 (needs network once)
./packaging/linux/build-release.sh   # builds PULSAR against it and makes both packages
```

The `-third-party-source` archive contains the same tarballs, so the FFmpeg and x264 build can be run offline
(`PULSAR_THIRD_PARTY_DIR=<dir>`).
