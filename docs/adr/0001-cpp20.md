# ADR 0001: Use C++20

## Status

Accepted

## Context

PULSAR needs a modern C++ baseline that is widely available on Linux toolchains and suitable for a long-lived native application.

## Decision

PULSAR uses C++20 as its baseline language standard.

## Consequences

The project can use C++20 standard-library features without adding external dependencies. Contributors need a compiler with C++20 support.
