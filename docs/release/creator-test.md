# Creator test (human gate)

Goal: find out whether a real creator can finish a video in PULSAR without opening another editor.

## Mission (give it verbatim; no tour, no hints about where tools are)

Gate 1:

> Con estos videos, música y sonidos, hacé un video completo de 2–3 minutos y dejalo listo para subir.

Gate 2 (second human, after the "professional + completeness" pass):

> Editá un video completo con PULSAR.

Give the tester a folder with ordinary material: a dozen clips, a few photos, one or two songs and
whatever sounds they like. Do not say that photos, colour cards, titles, fades or duplicate exist.

## Setup

1. Install the bundle (`tar xzf PULSAR-0.2.0-beta.1-linux-x86_64.tar.gz && ./PULSAR-0.2.0-beta.1/pulsar`, or the AppImage).
2. Put the material in one folder. It can be imported with **Importar una carpeta entera…** or dragged in.
3. Observe, do not help. Note the minute at which each question comes up.

## Log (write while they work)

| What | Notes |
|---|---|
| Things they looked for and did not find | |
| Things they asked for that PULSAR does not have | |
| Where they lost time (minutes, what they were doing) | |
| Repetitive or annoying actions | |
| Errors, crashes, anything that looked wrong | |
| Moments they said they would use another editor, and for what | |
| Is the exported file one they would publish? (picture, sound, titles, length) | |

## Pass criterion

The creator delivers a finished, uploadable MP4 **without opening another tool**, and calls the result
publishable. Every "I would use another editor for…" is a backlog item, ordered by how often it occurs.
