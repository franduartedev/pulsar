# Creator test (JAZ gate)

Goal: find out whether a real creator can finish a video in PULSAR without opening another editor.

## Mission (give it verbatim)

> Con estos videos, música y sonidos, hacé un video completo de 2–3 minutos y dejalo listo para subir.

## Setup

1. Install the bundle (`tar xzf PULSAR-0.1.0-beta-linux-x86_64.tar.gz && ./PULSAR-0.1.0-beta/pulsar`, or the AppImage).
2. Put the creator's videos, music and sounds in one folder. Import it with **Importar una carpeta entera…**
   (or drag assets from the library onto the timeline).
3. The tester gets no coaching. Observe, do not help.

## Log (write while they work)

| What | Notes |
|---|---|
| Things they looked for and did not find | |
| Repetitive or annoying actions | |
| Errors, crashes, anything that looked wrong | |
| Moments they said they would use another editor, and for what | |
| Did the exported file play correctly (picture, sound, titles, length)? | |

## Pass criterion

The creator delivers a finished, uploadable MP4 **without opening another tool**. Every
"I would use another editor for…" is a backlog item, ordered by how often it occurs.
