# PULSAR 0.1.0-beta — release notes

PULSAR is a lightweight desktop video editor (C++, Qt 6, FFmpeg). This is its first
public **beta**: the editing workflow is complete and tested, the feature set is
deliberately small, and the interface is in **Spanish**.

**Platform:** Linux x86_64. **Tested on:** Ubuntu 24.04 LTS (see *Packaging notes*).
Windows, macOS and Android are not supported yet.

## Run it

1. Download `PULSAR-0.1.0-beta-linux-x86_64.tar.gz` from the release page and check it against `SHA256SUMS`.
2. `tar xzf PULSAR-0.1.0-beta-linux-x86_64.tar.gz`
3. `cd PULSAR-0.1.0-beta && ./pulsar`

No Qt or FFmpeg installation is required. `./pulsar --version` prints `PULSAR 0.1.0-beta`.
An AppImage is also provided; on Ubuntu 22.04+ it needs `libfuse2` (or run it with
`--appimage-extract-and-run`).

## What you can do

1. **Import** videos, photos and audio (button, a whole folder, drag & drop onto the window, or *Ctrl+I*).
2. Place them on the single video track: drag them from the library onto the timeline, **Insertar** (at the playhead), **Al final** (right after the last clip, no gap) or double-click. Photos (PNG, JPEG, WebP) and **Placa de color** cards are clips like any other: 5 s by default, drag an edge to change the length.
3. **Cut** (*S*), **trim** (drag the edges of a selected clip, or *Q* / *W* to cut its start / end back to the playhead), **move** (drag), **delete** (*Supr*) or **delete and close the gap** (*Shift+Supr* or right-click). *Alt+←/→* select the previous / next clip. Clips snap to the edges of other clips, the playhead and zero (the **Snap** magnet button or *N* turns snapping off); they stop at their neighbours and never overlap.
4. **Undo / redo** (*Ctrl+Z* / *Ctrl+Shift+Z*, 256 steps).
5. **Audio:** add music or sound files on independent audio tracks, insert one of 37 built-in sound effects (*Sonidos* tab, ▶ to listen first), set gain (−60 to +12 dB), add a **fade in / fade out** (Inspector), **silence a clip's audio** (speaker icon on the clip, *Silenciar audio* in the Inspector, key *M*, or right-click the clip), and **Separar audio** from a video clip into its own synchronised audio clip.
5b. **Titles and polish:** *T* adds a title at the playhead (text, size, colour, position, shadow, background box, opacity); *Ctrl+D* duplicates the selected clip or title; *←/→* step one frame.
6. **Save** (*Ctrl+S*; asks where on the first save), reopen later (*Ctrl+O*). PULSAR asks before you lose unsaved changes.
7. **Export** to MP4 (H.264 video, AAC audio). A cancelled or failed export never replaces an existing good file.

## Known limitations

- **One video track.** No picture-in-picture, overlays, transitions, effects, subtitles or color tools.
- **Titles are static**: one font (Inter Bold), one style per title (colour, size, alignment, shadow, optional background box and opacity), no animation, no overlap between titles, minimum 0.25 s. A title needs at least one video clip.
- **Photos and colour cards**: PNG, JPEG and WebP only (no animated WebP/GIF, no SVG, no RAW); pictures above 100 megapixels are refused; transparency is flattened over black, so a logo with alpha cannot yet be used as an overlay. A title can be dragged anywhere in the picture (it stays fully inside the frame); a title's position is a fraction of the frame, so it follows an export at another size. A still has no audio.
- **Fades are audio only** and linear; there is no video fade, no cross-fade and no track-level gain/mute/solo.
- **Export is MP4 / H.264 + AAC only**, on the CPU; long or high-resolution projects take real time.
- **Autosave** keeps one recovery snapshot (every 30 s) in `~/.local/share/PULSAR/recovery`; it does not replace saving. Undo history is not recovered.
- **Missing media:** if a source file is moved or deleted the project still opens and the clip is shown as *Sin conexión*; it cannot be played or exported until the file is back at its original location. There is no "relink" yet.
- **Preview** is software-decoded: heavy 4K material may drop frames, and a small A/V offset can appear for a moment right after seeking. There are no proxies. Exports are exact regardless of preview performance.
- Timeline zoom: slider or *Ctrl + mouse wheel* (anchored at the pointer); *Shift + wheel* pans. Dragging media (footage, photos, colour cards, music) onto the timeline works; it cannot place a clip beyond the current end (drop at the right edge or use *Al final*). Right-click on a clip offers Cut / Silence / Detach audio / Delete.
- **Importing uses PULSAR's own dialog** (multi-select, folders). *Abrir proyecto* still uses Qt's own dialog (light theme, may show English labels, not the desktop's native one). **Save, Save As and Export ask for a typed path** (a default is suggested; a bare name lands in the same folder and the extension is added), because Qt 6.4's non-native dialog cannot create a new file name.
- The output stage is a soft knee (above 0.9 of full scale), not a look-ahead limiter: very loud material is rounded, not leveled. Lower the gain of the loudest clips.
- Preview scales mixed-size clips with nearest-neighbour; the export uses Lanczos.
- The project canvas is the first real video clip (a photo only decides it when there is no footage); a still of another aspect ratio is fitted with black bars, never stretched.
- A `.pulsar` file is not yet registered with the desktop (no MIME type), so double-clicking one in a file manager needs "Open with PULSAR"; the command line and drag-and-drop onto the window work.
- Undo history is kept in memory only and is limited to 256 steps.
- Waveform data is cached under `~/.cache/PULSAR/` and can be deleted safely.
- Audio output is played through Qt Multimedia (PipeWire/PulseAudio/ALSA); it has not been tested on every audio stack.
- The bundle is large (~250 MB installed) because it carries FFmpeg's full dependency set.

- **Delete and close the gap** moves every clip (any track) starting at or after the deleted clip's end; clips that start earlier, such as long music, stay where they are. If that would overlap a clip that stays, PULSAR refuses and changes nothing.
- Thumbnails are decoration: if one cannot be decoded (or the media is offline) the clip is simply shown without it.

## Reporting bugs

Open an issue with the *Bug report* template and include: PULSAR version
(`./pulsar --version`), distro and desktop (X11/Wayland), CPU/GPU/RAM, the codec and
resolution of the media involved, the steps, and the terminal output
(start PULSAR from a terminal; the project file helps if you can share it).

## Release gate (automated, run on the release candidate)

Debug and Release test suites; desktop smoke, export, ingest, safety and shutdown
integration tests; AddressSanitizer + UndefinedBehaviorSanitizer (leak detection on);
`git diff --check`; end-to-end project built from scratch (3 videos, trims, splits,
moves with snapping, independent audio, SFX, detach audio, gain/mute, undo/redo,
save → close → reopen → export) verified with `ffprobe`; clean-room launch of the
package in a bare Ubuntu 24.04 environment. Results are listed in the RC report.

## Packaging notes

- `packaging/linux/build-release.sh` builds both artifacts from a clean tree with pinned
  packaging tools (SHA-256 verified). Nothing is published by the script.
- Layout: `pulsar` (launcher) → `usr/bin/pulsar-desktop`, `usr/lib` (Qt 6, FFmpeg and their
  dependencies), `usr/plugins`, `usr/qml`, `usr/share/pulsar/assets` (sound pack).
  Resources are located relative to the executable (or `$PULSAR_ASSETS_DIR`); no
  build-time absolute paths are embedded.
- Not bundled, expected from the host: glibc, the GPU/OpenGL stack, and the X11/Wayland
  client libraries (the usual AppImage exclude list).
- **Built on Ubuntu 24.04 (glibc 2.39): the bundle runs on distributions with glibc ≥ 2.39.**
  Older distributions (e.g. Ubuntu 22.04, Debian 12) are not supported by this build.
- Tester-facing verification: `sha256sum -c SHA256SUMS`.

## Licence and third-party components

PULSAR is free software under the **GNU GPL, version 3 or any later version** (`GPL-3.0-or-later`, see `LICENSE`).
`THIRD_PARTY_NOTICES.md` (shipped in both packages) lists every component, its licence and where to get the source.
In short:

- **FFmpeg 6.1.1** is our own build of the unmodified upstream release, configured with `--enable-gpl --enable-version3`
  (no `--enable-nonfree`), with **x264** (GPL-2.0-or-later, static) for H.264 export and **dav1d** (BSD-2-Clause) for AV1.
  No libzvbi, x265 or Xvid. Exact configuration: `usr/share/doc/pulsar-third-party/FFMPEG-BUILDINFO.txt`.
- **Qt 6.4** (LGPL-3.0) and the remaining runtime libraries come unmodified from Ubuntu 24.04; the exact package
  list is `usr/share/doc/pulsar-third-party/PACKAGES.txt`, with each package's `copyright` file beside it.
- **Inter Bold** is SIL OFL 1.1. The sound pack is generated by PULSAR's own script.
- **Corresponding source** is published with each release: `PULSAR-0.1.0-beta-source.tar.gz` and
  `PULSAR-0.1.0-beta-third-party-source.tar.gz` (FFmpeg, x264, dav1d and the build recipe).
- Ingest note: the previous test builds used Ubuntu's FFmpeg, which could also decode JPEG XL through `libjxl`.
  JPEG XL is not in PULSAR's import list and is not supported; every other format we tested decodes identically.

## Decisions recorded for this release

- **Autosave / recovery:** not included. A safe design needs a recovery store, stale-lock
  handling and a restore prompt — a subsystem, not a patch. Beta ships solid manual save plus
  the unsaved-changes guard. Planned for 0.1.1.
- **Relink media:** not included; offline media fails safely (see limitations).
- **Windows readiness (not part of this release):** blockers are `/proc/self/exe`
  resource lookup (`runtime_resources.hpp`), POSIX `open/fsync/rename` in the atomic project
  writer (`file_project_repository.cpp`), path-separator handling in project locators,
  `__int128` use in time arithmetic (GCC/Clang only), and the packaging scripts.
