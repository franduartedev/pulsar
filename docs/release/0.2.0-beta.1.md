# PULSAR FIRST PUBLIC BETA — 0.2.0-beta.1

PULSAR is a native and lightweight desktop video editor written in C++, Qt 6 and FFmpeg. This
first public beta supports the complete workflow needed to build and export a
small real video while keeping project state, preview and export semantics
aligned.

**Platform:** Linux x86_64. The interface is currently in Spanish. Windows,
macOS and mobile builds are not available.

## Run it

Verify the downloaded files with `sha256sum -c SHA256SUMS`, then use either:

```sh
tar xzf PULSAR-0.2.0-beta.1-linux-x86_64.tar.gz
./PULSAR-0.2.0-beta.1/pulsar
```

or `./PULSAR-0.2.0-beta.1-x86_64.AppImage`. The AppImage may require `libfuse2`;
`--appimage-extract-and-run` works without FUSE. `--version` prints
`PULSAR 0.2.0-beta.1`.

## What works

- Import video, PNG/JPEG/WebP images and audio; multi-file/folder import and drag-and-drop.
- Cut, trim, arrange, duplicate and delete clips with magnetic snapping and undo/redo.
- Multiple visual tracks, direct Viewer move/scale, and picture-in-picture.
- Static titles and one cross-dissolve transition type.
- Detach embedded audio without doubled sound; independent audio clips/tracks.
- Filled asynchronous waveforms, per-clip gain, mute, solo and audio fades.
- 37 original built-in sound effects with audition before insertion.
- Save and reopen `.pulsar` projects, autosave/recovery and offline-media states.
- MP4 export (H.264 video + AAC audio), with Original/1080p/720p output choices;
  export refuses to overwrite media files referenced by the project.
- Preview and export use the same visual composition plan and transformed-pixel compositor.

## Known limitations

- Transformed/multi-layer composition is CPU-only. High-resolution projects can
  render preview frames slowly; export remains authoritative.
- Titles are static. Rotation is adjusted in the Inspector rather than by a Viewer handle.
- Cross dissolve is the only transition type and needs a valid incoming source handle.
- No GPU renderer, E6 Adaptive Engine, proxy workflow, effects catalogue,
  subtitles, keyframes, masks, AI, cloud or collaboration features.
- Import supports PNG, JPEG and WebP stills; no SVG, RAW, animated GIF/WebP or relink UI.
- Export is MP4/H.264/AAC only. This Ubuntu 24.04 package requires glibc 2.39 or newer
  and host graphics/X11/Wayland libraries.
- Linux x86_64 is the only packaged platform for this beta.

### Human-validated media checks

- **Transparent PNG overlays — PASS:** validated on the real desktop in preview
  and exported output. Alpha behaved correctly in the tested overlay workflow.
- **Cellphone vertical video — PASS:** real cellphone footage displayed with the

  compatibility may still vary by source.

## Reporting bugs

Open a GitHub issue and include the PULSAR version, Linux distribution, X11 or
Wayland session, CPU/GPU/RAM, source codec/resolution, exact steps, terminal
output and (when shareable) the project file.
