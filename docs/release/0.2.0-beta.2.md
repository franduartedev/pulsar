# PULSAR — 0.2.0-beta.2

Candidate release focused on Windows readiness and audio V2 edit stability.

## Status

This document describes the beta.2 candidate. It is not a release announcement until
the Linux package, Windows package and both manual platform gates have been approved.

Automated validation on the integration baseline:

- Linux CI: 62/62 tests.
- Windows CI: 62/62 tests.
- Legacy project restore, project persistence and MP4 export are covered by the suite.

Manual validation recorded separately:

- Windows editor: adding overlapping clips did not restart audio and the editor behaved
  correctly.

## Changes since beta.1

- Audio V2 preserves the editorial position when the timeline snapshot changes during
  playback.
- Paused playback and resume preserve the current position.
- Shifted source ranges and generation boundaries are handled without contaminating the
  new audio queue.
- Windows decoder/source lifetime handling is hardened for paused document and clip edits.
- The portable Windows packaging path includes transitive FFmpeg runtime DLLs.

## Installation

### Windows portable ZIP

Extract `PULSAR-0.2.0-beta.2-windows-x86_64.zip` to a writable directory and launch:

```text
bin/pulsar-desktop.exe
```

The ZIP includes Qt, QML, the MSVC runtime and FFmpeg DLLs. It does not install a system-wide
application or alter the project format.

### Linux AppImage

```sh
chmod +x PULSAR-0.2.0-beta.2-x86_64.AppImage
./PULSAR-0.2.0-beta.2-x86_64.AppImage
```

If FUSE 2 is unavailable, use `--appimage-extract-and-run`.

## Compatibility and formats

- Existing `.pulsar` projects, including the v1 fixture, remain readable.
- Export is MP4 with H.264 video and AAC audio.
- Import supports video, PNG/JPEG/WebP stills and audio formats supported by the build.
- Preview and export use the existing shared composition/audio semantics.

## Known limitations

- Preview composition is CPU-based and can be slow for large or multi-layer projects.
- Proxy media is not implemented yet.
- GPU preview and hardware-adaptive decoding are not implemented.
- Export is primarily MP4/H.264/AAC; vertical presets require separate final validation.
- No relink UI for missing media, masks, general transform keyframes or collaboration.
- Linux packages target compatible x86_64 systems and may require FUSE 2 for AppImage.
