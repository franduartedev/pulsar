# Bundled font

| | |
|---|---|
| Font | **Inter Bold** (`Inter-Bold.otf`) |
| Author | The Inter Project Authors — https://github.com/rsms/inter |
| Licence | SIL Open Font License 1.1 (`OFL.txt`) |
| Origin | Unmodified file from the Debian/Ubuntu package `fonts-inter` |
| Used for | Title text in previews and exports (the only font titles use) |

The font ships inside PULSAR's own `assets/fonts/` folder and is loaded by the application at
run time; PULSAR does not install it system-wide and never depends on the host's fonts for
titles, so a title looks the same on every machine.
